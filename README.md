# Product Inventory System (C)

A beginner-friendly product inventory program built in C to practise structures, functions, loops, and dynamic memory allocation.

## Features

* Accepts multiple product records.
* Stores product names, IDs, prices, and quantities.
* Displays the entered product information.
* Uses dynamic memory allocation to store product records.

## Concepts Practised

* Structures (`struct`)
* Functions and function declarations
* Arrays of structures
* Loops and user input
* Dynamic memory allocation using `malloc()`
* Memory management using `free()`

## How to Run

**Requirements:** A C compiler, such as GCC.

1. Clone or download this repository.

2. Open a terminal in the project directory.

3. Compile the program:

   ```bash
   gcc product.c -o product
   ```

4. Run the program:

   **Windows:**

   ```bash
   .\product.exe
   ```

   **Linux/macOS:**

   ```bash
   ./product
   ```
